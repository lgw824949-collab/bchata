# 🎪 오늘밤! BAR (Today Bamba) - 서비스 운영 매뉴얼

오늘밤! BAR는 AI 기반의 자동 제보 시스템과 고정밀 관리자 대시보드를 갖춘 댄스 파티 플랫폼입니다.

## 🚀 핵심 운영 원칙 (System Instructions)

### 1. 데이터 격리 및 초기화 (Stateless Processing)
- 모든 이미지 업로드 이벤트는 독립적인 세션으로 간주합니다.
- 새 이미지가 업로드되면 `title`, `location`, `date`, `time`, `fee` 등의 모든 변수를 **빈 문자열("")로 하드 리셋**한 후 분석을 시작합니다.
- 이전 요청의 데이터가 현재 요청에 결합되는 '데이터 오염'을 원천 차단합니다.

### 2. 증거 기반 AI 제보 엔진 (Evidence-Based Engine)
- **우선순위 1**: `src/lib/BarLib.js` 내의 마스터 DB와 텍스트를 전수 대조하여 상호명과 주소를 확정합니다.
- **우선순위 2**: DB에 없는 경우에만 정규식(Regex)을 통해 광역시도(17개 시·도) 및 상세 주소를 추출합니다.
- 분석이 불확실할 경우 빈칸으로 남겨두어 관리자의 수동 확인을 유도합니다.

### 3. 모바일 최적화 및 디자인 규격
- **제목 제한**: 모든 파티 제목은 모바일 레이아웃 보호를 위해 **최대 40자**로 제한됩니다.
- **활성 마킹**: 주간 캘린더에서 선택된 날짜는 **그린 서클(#1D9E75)**과 아래의 **포인트 점(Dot)**으로 강조됩니다.
- **반응성**: 안드로이드(Samsung)와 iOS(Apple) 환경에서 모두 동일한 UX를 보장합니다.

### 4. 관리자 승인 인프라
- **선 수정 시스템**: 관리자는 승인 전 제보 내용을 직접 수정할 수 있는 권한을 가집니다.
- **UUID 트랜잭션**: 모든 ID는 데이터베이스 규격에 따라 UUID 형식을 사용하며, 대기 목록 삭제와 정식 목록 등록이 한 번에 이루어집니다.
- **즉각 갱신**: 승인 완료 시 홈 화면으로 자동 이동하여 등록 결과를 실시간으로 확인합니다.

## 🛠️ 기술 스택
- **Frontend**: React, Vite, Framer Motion
- **Backend**: Supabase (PostgreSQL, Storage)
- **Logic**: Evidence-Based OCR Mapping System
