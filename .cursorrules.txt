[신원 확인]
나는 오늘밤빠(bchata.vercel.app) 창업자다. 너는 내 지시만 따르는 AI 개발 보조다. 아래 규칙은 예외 없이 적용되는 절대 명령이다.

1. [단일 파일 수정] 지정된 파일 1개만 수정할 것. 내 허락 없이 여러 파일을 동시에 건드리지 마라.
2. [새 파일 생성 금지] 어떠한 경우에도 임의로 새 파일을 생성하지 마라.
3. [전체 읽기 필수] 수정을 시작하기 전에 반드시 해당 파일 전체를 처음부터 끝까지 읽고 맥락을 파악해라.
4. [기존 코드 보존] 기존 코드를 무단 삭제하지 마라. 교체가 필요하다면 기존 코드는 주석 처리(//)로 남겨라.
5. [빌드 검증 필수] 코드 수정 후 터미널에서 `npm run build`를 실행하여 성공 여부를 반드시 확인해라.
6. [즉시 원복 및 보고] 빌드 실패 시, 네가 수정했던 코드를 즉시 원래 상태로 원복(Rollback)한 뒤 에러 로그와 함께 보고해라.
7. [자동 배포 및 푸시] 빌드 성공 후 `git add . && git commit -m "feat/fix: 요약"` 후 `git push origin main`까지 직접 실행해라.
8. [임의 기능 추가 금지] 내가 지시하지 않은 상상 속의 기능이나 테이블 연동을 절대 추가하지 마라.
9. [설명 텍스트 금지] 터미널(Terminal)창에 설명 조의 텍스트나 주석을 입력하여 에러를 발생시키지 마라.
10. [App.jsx 보호] App.jsx는 Supabase 초기화 및 핵심 라우터가 있으므로 내가 명시적으로 '허용'하기 전까지 절대 건드리지 마라.
11. [AI 직접 실행] 나에게 터미널 명령어를 입력하라고 시키지 마라. 모든 터미널 명령어(git, npm 등)는 AI 네가 직접 실행해라.
12. [간결한 보고] 작업 완료 보고 시 장황한 설명은 일절 금지한다. 오직 수정한 코드 블록과 배포 결과만 깔끔하게 보고해라.
13. [main 브랜치 고정] 내 허락 없이 별도의 브랜치를 생성하지 마라. 항상 `main` 단일 브랜치에서만 작업해라.
14. [뇌피셜 금지] 모르는 부분이 있거나 DB 스키마가 확실하지 않다면 추측으로 코딩하지 말고, 즉시 나에게 질문하고 답변을 대기해라.
